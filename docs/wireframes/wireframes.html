Overview

User flow

From sign-in to operator verdict. Each screen is its own route in the app.
Sign inGoogle or email
→
DashboardFleet health and open alerts
→
Live monitorLatest values and charts
→
Flagged?Classification from rules, ML and context
→
Alert reviewReasons, readings, verdict
→
Label storeVerdict feeds calibration

Classification states

  • NORMAL: nothing unusual
  • WATCH: mildly unusual
  • SUSPICIOUS: unusual and unexplained
  • PROBABLE_SENSOR_FAULT: rules or model point at the instrument
  • LIKELY_GENUINE_EXTREME: context agrees it is real weather
  • INSUFFICIENT_CONTEXT: no evidence either way

Design rules

  • One screen, one route, one node on the canvas
  • Raw observations shown as received, never edited
  • Every alert shows its reason codes
  • Operator verdict is one click from the alert drawer
  • Red = fault, amber = watch, green = genuine or normal
